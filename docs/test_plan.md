# Test plan

Run `py -m pytest`. Unit cases cover half-up rounding, invalid amounts, onboarding day 60, Rs 100 fee boundary, co-funded discount with packaging cap, customer and restaurant cancellations, discount-adjusted full refunds, refund funding reasons, and rating uplift. Integration cases use isolated SQLite databases to cover duplicate imports, Sunday 23:59 dispute opening and Tuesday 08:00 closing, correct close-week assignment, TDS crossing-order behavior and per-order report, rating averages below/at 3.5, suspension, ad spend above payout and carry, platform minimum/entered fees, delivery-fee reporting, platform discount reimbursement, negative cancellation payout, audit idempotency, and calculated exports. The original sample has one order; it cannot validate the full hidden multiweek dataset.
